# Humo-pre-care
Prototipo MVP di "Humo": un funnel di pre-triage empatico.
**Progetto non ufficiale** realizzato come esercizio strategico.
Humo è un concept per un funnel di **"Pre-Care"**. Si tratta di un bot di micro-journaling (simulato qui via web, ma pensato per WhatsApp) progettato per abbattere le barriere d'ingresso e ottimizzare il Costo di Acquisizione Cliente (CAC).
